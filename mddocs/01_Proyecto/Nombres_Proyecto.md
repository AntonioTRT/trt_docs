# Nombres del proyecto

> Estado: Parcial.

- **TRT** = *Tool Runtime Terminal*. Es el nombre oficial del framework.
- Nombres de repositorio/módulo: `TRT-cli`, `TRT-core`, `TRT_HW`.
- Comando de terminal: `trt`.
- Marca del trío `TRT-*`: usar siempre "TRT-cli", "TRT-core" (con guion) al hablar de software y "TRT_HW" para el hardware.

Las alternativas de nombre consideradas y la justificación de la elección no están registradas en los repositorios; si se recuperan, añadirlas aquí.
